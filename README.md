# Music Player

Player de música desenvolvido com **HTML, CSS e JavaScript**, com interface inspirada em aplicativos de streaming musical. Projeto de estudo para praticar manipulação do DOM, eventos do navegador e construção de interfaces web.

## Demonstração

[Acessar Music Player](https://music-player-lake-five.vercel.app/)

## Tecnologias

- HTML5 — estrutura da interface
- CSS3 — layout e componentes visuais
- JavaScript — comportamento do player

## Executar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/guilhermedospassos/music-player.git
   ```
2. Abra `index.html` no navegador ou utilize um servidor local simples, como o Live Server do VS Code.

Os recursos de áudio e imagem usados pelo projeto estão organizados nas pastas `songs/` e `images/`.

## Estrutura

- `index.html` — interface
- `style.css` — estilos
- `script.js` — lógica do player
- `songs/` e `images/` — arquivos usados na experiência
